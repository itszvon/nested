# Surface brief — the app shell (`/app`)

Mode: Operate

## Direction contract

**THESIS.** The file tree is a ledger: every row is a line with a right-aligned
column for its size or language, separated by hairlines, hierarchy shown by
indentation. The surface refuses the category default of floating rounded cards,
drop shadows, and sparse iconography.

**OWN-WORLD.** Near-black ground with a green undertone (`#0a0c0b`), panel
`#0e1110`, hairlines `#1e2421` doing all structural work, ink `#e9e7e1` and
`#9aa09a`, one oxblood accent `#a8442f` used only for selection, the dirty dot,
and the primary button. No radii, no shadows, no gradients. Tabular numerals in
both faces.

**STORY.** The user sees a structured record of their material: what exists, how
big it is, when it last changed. They open a row, work in the editor beside it,
and save deliberately. Nothing invites exploration; everything invites reading.

**FIRST VIEWPORT.** A 300px sidebar of 28px rows with 1px rules, the disclosure
caret and name left, a mono number right. To its right, a 44px ledger heading:
file name, kind, revision, bytes, last-save stamp, then Save File (solid oxblood)
and Save Project (outlined) at the far right. Below, the editor pane.

**FORM.** Grounded direction 3 of 7 (ledger / account book). Seed key
`29da04e6`. Challengers declined: variable-font specimen, character catalogue;
design annual plate kept as a donor of hairline-grid discipline.

**FINISH.** Unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.

## Scope

Read-only tree, selection, URL contract, empty states. No editing, no saving, no
creation until phases 4–6.

## Unresolved
