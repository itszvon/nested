# Nested 0.1.2 (desktop)

Brings the desktop bundle up to the current site: new sign-in page, Markdown
toolbar, download page.

## Changes since 0.1.0

- Sign-in page: blueprint grid, nested-square motif, ember glow.
- Markdown toolbar (bold, italic, H1, H2, list, inline code) with `Ctrl+B` / `Ctrl+I`.
- Imported `.txt` files are stored as `.md`.
- Window size and position are restored and clamped to visible displays.
- `Help -> About` shows version, Electron, Chromium, Node and OS, with a copy button.
- Main-process crashes are logged to `%APPDATA%\nested-desktop\logs\main.log` (rotated at 1 MB).
- The window injects the loopback handshake header; 0.1.0 returned "Forbidden" on every page.
- Startup refuses a port owned by another process instead of attaching to it.
- Application icon.
