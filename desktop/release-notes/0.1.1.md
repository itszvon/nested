# Nested 0.1.1 (desktop)

First build that can sign in. Replaces 0.1.0, which returned "Forbidden" on
every page because the window never sent the loopback handshake header.

## Fixes

- The window now injects `x-nested-desktop` on requests to its own origin.
- Startup refuses a port owned by another process instead of attaching to it.
- `Nested: Help -> About` shows version, Electron, Chromium, Node and OS, with
  a copy button.
- Main-process crashes are written to `%APPDATA%\nested-desktop\logs\main.log`
  (rotated at 1 MB).
- Application icon.
- Window size and position restored across launches (clamped to visible displays).
- `desktop/NOTICE.md` licence inventory.
- Download page on the site links to these artifacts.
- Sign-in page: blueprint grid, nested-square motif, ember glow.
- Markdown toolbar (bold, italic, H1, H2, list, inline code) with Ctrl+B / Ctrl+I.
- Imported `.txt` files are stored as `.md`.

## Known limits

- Online only; the app needs the network for every read and write.
- Windows x64 only in 0.1.x.
- No upgrade test from 0.1.0 has been performed yet.
